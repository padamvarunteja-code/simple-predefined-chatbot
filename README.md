Simple Predefined Chatbot 🤖
A beginner-friendly rule-based chatbot built with Python.
📌 About the Project
This is a simple chatbot that responds to a set of predefined questions and commands. It was developed and tested using Visual Studio Code (VS Code).
The project helped me understand the basics of:
Python programming
Conditional statements
User input and output
Basic chatbot logic
Handling predefined responses
🛠️ Technologies Used
Python 🐍
Visual Studio Code 💻
💬 How It Works
The chatbot takes input from the user and checks it against predefined questions. If the input matches one of the programmed questions, the chatbot provides the corresponding response.
🎯 Learning Outcome
Through this project, I learned how basic rule-based chatbots work and gained practical experience writing and running Python programs in VS Code.
🚀 Future Improvements
I plan to improve this project by adding:
More questions and responses
Better conversation handling
More advanced AI capabilities
